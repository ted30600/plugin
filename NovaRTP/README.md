# NovaRTP

Plugin Paper Minecraft 1.21.10.

## Commande
/rtp

Alias : /randomtp, /randomteleport

Le menu propose Overworld, Nether, The End et Fermer.
Le plugin cherche une position sûre entre 500 et 5000 blocs du point 0,0.

## Compilation
mvn package

Le fichier généré est target/NovaRTP-1.0.0.jar.
