# NovaKamoof

Plugin Paper 26.2 pour NovaStream, recréant les mécaniques publiques principales du Kamoof SMP Saison 2.

## Fonctionnalités
- Une tête de joueur est ajoutée au butin à sa mort.
- Clic droit avec la tête : identité, nom et skin de la victime.
- /undisguise : retour à l'identité originale.
- Mourir retire le déguisement.
- Rituel avec 9 têtes.
- Pacte Ensanglanté : +5 cœurs et 3 têtes à la prochaine mort.
- Pacte Oublié : aucune tête à la prochaine mort et Faiblesse permanente.

## Installation
1. Installer NickAPI 7.6.
2. Mettre NovaKamoof-1.0.0.jar dans plugins.
3. Redémarrer Paper 1.21.11.

## Compilation
Java 25 + Maven : mvn clean package
Le JAR est créé dans target/NovaKamoof-1.0.0.jar.

Projet indépendant : les mécaniques ont été réimplémentées à partir de la description publique du Kamoof SMP Saison 2.
