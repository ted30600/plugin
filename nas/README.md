# Virtual NAS

Interface web de démonstration avec connexion, trois gestionnaires de fichiers, ajout de fichiers/photos/vidéos et téléchargement.

## Compte de démonstration

- Identifiant : `admin`
- Mot de passe : `admin123`

Les données sont stockées localement dans le navigateur (IndexedDB). Ce n'est pas un stockage serveur réel.
